Phase 01 — ATTRACT

Generate awareness and drive qualified traffic to landing pages

🤖 FULLY AUTONOMOUS
🤖 What Claw Does
Content Generation Writes SEO-optimized blog posts, social media content, and ad copy in EN+AR based on battle card and personas.
Landing Page Deploy Builds, styles, and deploys bilingual landing pages to Netlify with real content — no placeholders.
Ad Creative Briefs Produces platform-specific creative briefs (Meta, LinkedIn, Google) with targeting, copy, and CTAs.
SEO Optimization Generates meta tags, structured data, sitemaps, and keyword-aligned content for Saudi market.
🛠️ Tools Used
GitHub + Netlify Repo hosting and auto-deploy on every push. Branch-based preview URLs for testing. netlify.app · github.com/siyaida
OpenClaw Subagents Parallel execution of creative, copy, and code tasks via subagent delegation. kimi/k2p6 · depth-1 subagents
Web Research (kimi_search) Real-time research on Saudi employers, competitors, keywords, and market positioning. web search · data validation
kimiim-cli Cross-platform message coordination when content needs human review before publish. Feishu · Discord · group chats
📄 Files Read
battle-card.md Value props, ICPs, regions, channels — the single source of truth for all content. missions/jic-gw-engineering-management/
anchor-employers.csv Top-50 Saudi employers with confidence scores for targeted outreach. confidence-tagged · public sources
ad-creative-brief.md Platform specs, audience targeting, budget recommendations, creative assets needed.
AGENT-BOOT.md Agent context, mission parameters, and operating constraints for any new claw instance. missions/cross-agent-operations/
📤 Expected Output
3+ live landing pages (AR+EN) on Netlify
Ad creative brief with platform-specific assets
SEO-optimized blog posts and social content
Lead magnet (e-book, webinar, or checklist)
Analytics-ready UTM tracking schema

Phase 02 — CAPTURE

Convert traffic into identifiable leads via forms, chat, and calendar

🤖 AGENT + 👤 HUMAN
🤖 What Claw Does
Form Builder Creates intake forms with validation, bilingual labels, and required-field logic. Connects to n8n webhook.
CRM Schema Design Defines lead schema (fields, stages, tags) and creates the Airtable/Notion/DB structure.
Chatbot Script Builds conversational flow for WhatsApp/website chat with qualification questions and handoff triggers.
Calendar Integration Embeds Cal.com booking widget with availability rules, buffer times, and confirmation emails.
🛠️ Tools Used
n8n / ActivePieces Webhook ingestion, lead routing, and auto-response workflows. Docker-compose stack included. self-hosted · docker-compose
Airtable / Notion API Lead database with views for pipeline, scoring, and regional segmentation.
Cal.com Open-source scheduling. Embedded widget. Automatic timezone handling for Saudi GMT+3. cal.com · self-hostable
WhatsApp Business API Conversational intake via WhatsApp with template messages and session management. Meta Business · requires creds
👤 Human Gate
WhatsApp Business Approval Human must provide Meta Business account credentials and approve message templates.
Cal.com Account Setup Human creates account, sets availability, and connects calendar. Agent embeds the widget.
Form Approval Agent proposes form fields. Human confirms or adds custom questions before go-live.
📤 Expected Output
Live intake form connected to CRM
n8n/ActivePieces workflow handling form → CRM → auto-email
WhatsApp chatbot script (Arabic + English)
Cal.com booking page embedded on site
Lead database with pipeline stages

Phase 03 — QUALIFY

Score, segment, and enrich leads for priority routing

🤖 FULLY AUTONOMOUS
🤖 What Claw Does
Lead Scoring Engine Assigns scores based on company tier, job title, region, engagement history, and form responses. Auto-updates in CRM.
Segmentation Logic Buckets leads into B2C (engineers) vs B2B (HR/L&D) and regional cohorts (Riyadh, Jeddah, Dammam, etc.).
Data Enrichment Cross-references employer database, LinkedIn data, and public records to validate lead quality.
Priority Routing High-score leads get fast-tracked to consultation. Low-score leads enter extended nurture sequence.
🛠️ Tools Used
Airtable / Notion Lead database with formula fields for scoring, views for segments, and automations for routing.
n8n Workflows Scoring triggers, segment updates, and routing decisions executed automatically on every lead change.
Anchor Employers DB Internal reference for employer tier classification and partnership status lookup.
📄 Files Read
crm-schema.md Field definitions, stage transitions, scoring weights, and validation rules. missions/jic-gw-engineering-management/crm-schema/
anchor-employers.csv Employer tier data for B2B lead classification and partnership scoring.
objection-playbook.md Used to tag leads by likely objections for tailored nurture sequences.
📤 Expected Output
Scored lead database with A/B/C tiers
Segmented pipelines (B2C vs B2B, by region)
Auto-routing rules (high → consult, low → nurture)
Enrichment data appended to each lead record

Phase 05 — CONSULT

Human-in-the-loop: discovery calls, Q&A, and enrollment counseling

👤 HUMAN REQUIRED
👤 What Human Does
Discovery Calls 30-45 min video calls via Cal.com. Understands goals, answers objections, builds trust. Cannot be automated.
Enrollment Counseling Guides prospects through program fit, financing options, and career outcomes. Requires empathy and cultural fluency.
Objection Handling Live Real-time objection resolution using playbook as reference, but adapting to specific prospect context.
🛠️ Tools Used
Cal.com Booking, reminders, video links, and follow-up scheduling. Integrates with Google/Outlook calendar. cal.com · zoom/google-meet
Info-Session Script Agent-generated script with talking points, FAQs, and objection counters. Human adapts live. missions/jic-gw-engineering-management/
CRM Views Pre-filtered views showing high-score leads ready for consultation. Human picks from queue.
📄 Files Read
info-session-script.md Full script with opening, value props, program details, pricing, FAQs, and closing. Bilingual.
objection-playbook.md 15 objections with scripted counters, evidence links, and tone guidance for live use.
battle-card.md Value propositions, differentiators, and proof points to reference during calls.
📤 Expected Output
Qualified prospects ready to enroll
Call notes logged in CRM with next actions
Objections encountered → playbook updates
Consultation → MOU pipeline visibility
✍️

Phase 06 — CLOSE

MOU signing, payment processing, and enrollment confirmation

🤖 AGENT + 👤 HUMAN
🤖 What Claw Does
MOU Generation Auto-fills MOU template with prospect data, program details, and terms. Produces PDF via browser automation.
Payment Link Generation Creates payment links/coupons for deposit collection via Stripe or local Saudi payment processor.
Enrollment Confirmation Sends automated welcome pack (email + WhatsApp) with onboarding instructions and community invite.
🛠️ Tools Used
MOU Template Engine Handlebars-based template with {{prospect}}, {{program}}, {{price}} bindings. Auto-generated PDF.
Stripe / Local Processor Payment collection with automatic enrollment status update on successful payment.
CRM Automation Moves lead from "Consulted" → "MOU Sent" → "Deposit Paid" → "Enrolled" automatically.
👤 Human Gate
MOU Review & Send Human reviews auto-generated MOU for accuracy before sending to prospect for e-signature.
Payment Verification Human confirms bank transfer or payment receipt before marking enrollment complete.
Exception Handling Custom payment plans, corporate invoicing, and scholarship approvals require human decision.
📤 Expected Output
Signed MOU (PDF) in document storage
Deposit received and recorded
Enrollment confirmation sent (email + WhatsApp)
CRM updated: lead → enrolled student
Onboarding sequence triggered automatically
🎓

Phase 07 — TRANSFORM

Onboarding, community, alumni network, and continuous improvement

🤖 AGENT + 👤 HUMAN
🤖 What Claw Does
Onboarding Sequence Automated welcome series: pre-reading, platform access, cohort intro, and first-week checklist.
Community Setup Creates Discord/WhatsApp group, pins rules, adds bots, and invites enrolled students.
Alumni Content Engine Generates alumni spotlights, career outcome stats, and testimonials for future marketing.
Feedback Loop Analyzes consultation notes, objections, and drop-offs to update playbooks and templates.
🛠️ Tools Used
Discord / WhatsApp Groups Community platform for cohort bonding, Q&A, and peer support. Bot-managed with rules.
GitHub / Notion Documentation hub for curriculum, resources, and alumni directory.
KPI Dashboard Auto-updated metrics: leads → consults → closes → enrollments → completion → alumni.
👤 Human Gate
Teaching & Delivery Program faculty deliver curriculum. Agent supports with materials, not instruction.
Community Moderation Human moderators manage community tone, resolve conflicts, and facilitate connections.
Playbook Iteration Human reviews agent-generated playbook updates and approves changes based on ground truth.
📤 Expected Output
Onboarded cohort with 90%+ first-week engagement
Active community (Discord/WhatsApp) with norms set
Alumni testimonials and case studies bank
Updated objection playbook from real data
KPI dashboard showing full funnel metrics
